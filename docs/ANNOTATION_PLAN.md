# 标注与测量交付计划

更新：2026-11-02。状态：待实现。本文细化已确认范围，不代表工具已经可用。

## 实施前提与顺序

桌面多视口显示正确性尚未通过；先解决显示与坐标一致性，再开放测量。当前 Web 已上线不等于桌面验收完成。领域真源沿用 ADR-014 的 `MeasurementRecord` 与 `MeasurementPort`，不另建 CS3D 私有标注作为第二真源。实施前修订现有简化模型，明确源 SOP/帧引用、坐标与有效性，供保存恢复和 SR/GSPS 共用。

| 增量 | 交付范围 | 完成门槛 |
| --- | --- | --- |
| A 基础闭环 | 原始 Stack 的直线测距、箭头与文字备注；标注列表、选中、编辑、删除、撤销/重做 | 单视口与独立分屏归属正确；切层、缩放、平移后位置正确；删除可恢复 |
| B 区域和角度 | 矩形/椭圆 ROI、三点角、Cobb 角；自由轮廓单独增量 | 各向异性像素、灰度换算、退化几何与控制点编辑均覆盖 |
| C 保存与交换 | 用户显式保存/恢复；与 PNG、DICOM SR、GSPS 共用冻结快照 | 恢复后继续编辑；源图/帧引用完整；限定工具逐项读回与第三方查看器验收 |

不在降采样 MPR 上输出测量值。MPR 准星是导航工具，不混入测量记录。定位像和未校准 SC 可作适用的图形/文字备注；没有可信物理标定时，不输出伪毫米或伪 HU。

## 交互契约

| 动作 | 行为 |
| --- | --- |
| 开始绘制 | 明确选中工具；先在当前原始影像创建草稿，不写入正式记录 |
| 完成绘制 | 直线/矩形/椭圆按下拖动释放；箭头完成几何后编辑备注；角度与 Cobb 角按工具提示逐点完成；自由轮廓完成方式在该增量内单独验收 |
| 取消草稿 | Esc 取消，不留下半成品记录；切换影像、布局或工具时同样取消草稿 |
| 选中 | 点击图形或列表项；显示控制点与当前选中状态，避免误删其他帧的标注 |
| 修改 | 拖动控制点修改几何、拖动图形移动；释放时形成一次历史记录；文字可从列表或编辑入口修改 |
| 删除选中 | 工具条/列表删除按钮与 Delete/Backspace 等价；焦点在输入框时保留文本编辑行为；删除后可撤销 |
| 清空 | 明确选择“当前帧 / 当前序列”，展示数量并确认；不隐式清空整个检查；撤销恢复该批记录 |
| 撤销/重做 | 创建、移动、控制点修改、备注编辑、删除均纳入；新操作后清除重做分支；快捷键避开输入控件 |
| 隐藏/显示 | 仅影响展示，不删除记录；导出时明确是否包含隐藏项，不能静默丢弃 |
| 切帧/切序列 | 图形只显示在所属 SOP 实例及帧上；列表可定位到源图；同 UID 的新导入会话不自动继承未核对的内容 |
| 保存/离开 | 默认会话内保存；首次持久化需用户显式同意；点击 Logo 返回首页保留会话并提供「继续阅片」，不触发丢弃确认；关闭或替换含未保存修改的会话时提供保存/丢弃/取消确认 |

测量面板常显“测量值仅供参考，未经临床验证”。鼠标移动只更新渲染层，结束交互后提交领域记录，遵守 R4。待确认的持久化介质按现有架构问题 Q2 单独决策，不默认启用患者数据缓存。

## 正确性和验收

- 坐标必须记录源影像和帧号；存储格式版本化，源图不存在时给出明确提示，不把标注放到看似相近的其他影像。
- 直线长度使用行/列物理间距；角度处理非等距像素；重合点、零长度线、空区域不产生有效数值。
- ROI 数值来自全分辨率原始像素并应用 Modality LUT 或 slope/intercept；是否能标作 HU 还要检查适用模态与变换语义，MR 灰度不能标 HU。
- 取消、错误、卸载、快速切层后不能残留草稿或旧控制点；拖动过程中不能误触翻层或准星导航。
- 保存恢复比对 ID、源 SOP/帧、几何、备注、单位、数值及有效性；中文备注、跨帧、删除后保存、撤销后保存分别覆盖。
- 数值与状态机单元/集成测试必须导入实际实现，关键数值逻辑做变异自检。桌面与 Web 的实际交互分别验收，独立评审另出报告。
- 导出按 [EXPORT_PLAN.md](EXPORT_PLAN.md) 执行；原始 DICOM 保持字节不变，新增测量与备注不伪称已经写入原图。
