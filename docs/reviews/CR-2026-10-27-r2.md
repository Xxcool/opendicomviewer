### 3.1 唯一未修复项：基准朝向仍取自首层

`packages/core/pipeline/sort.ts:88`：

```ts
const baseNormal = computeNormal(firstPlane.imageOrientationPatient);
```

**问题**：基准朝向取自数组第一个元素。若序列中异向切片恰好排在首位（混合序列、混入定位像/Scout 的常见情形），则**所有正确切片都会被判定为"朝向不一致"而剔除，最终只剩那一层异向切片**。

结果不是报错，而是一个**看起来合法的 1 层序列**——比直接失败更危险。

**实测**（补充用例，异向层置于 `[0]`）：

```
[审查] sorted=1 excluded=2 codes=ORIENTATION_MISMATCH
AssertionError: expected 1 to be 2
```

现有 S5 测试之所以通过，是因为**异常层被放在了数组末尾**。这属于"测试恰好避开了失败路径"。

**正确做法**：基准朝向用**多数投票**，而非取首元素。建议实现：

```ts
function pickDominantNormal(planes: readonly ImagePlane[]): Vec3 {
  // 按 1e-3 精度量化 IOP，统计出现次数最多者作为基准
  const buckets = new Map<string, { count: number; normal: Vec3 }>();
  for (const p of planes) {
    const n = computeNormal(p.imageOrientationPatient);
    const key = n.map((v) => Math.round(v * 1000) / 1000).join(',');
    const hit = buckets.get(key);
    if (hit) hit.count += 1;
    else buckets.set(key, { count: 1, normal: n });
  }
  let best: { count: number; normal: Vec3 } | undefined;
  for (const v of buckets.values()) if (!best || v.count > best.count) best = v;
  return best?.normal ?? computeNormal(planes[0].imageOrientationPatient);
}
```

**必须补的测试**：

```ts
it('S5 反例：异向层位于首位时，不得把正确切片全部剔除', () => {
  const outlier = createPlane(5, 99, { imageOrientationPatient: SAGITTAL_IOP });
  const result = sortByPosition([outlier, createPlane(0, 1), createPlane(2, 2)]);
  expect(result.sortedPlanes).toHaveLength(2);   // 当前返回 1
  expect(result.excludedPlanes).toHaveLength(1);
});
```

> 附带说明：`MISSING_GEOMETRY` 分支目前接近不可达——回退链末尾是 `sliceThickness ?? 1.0`，只有 `sliceThickness === 0` 才会触发。保留无害，但它并不能在现实中保底。
