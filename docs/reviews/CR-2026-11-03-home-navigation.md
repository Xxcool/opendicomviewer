# 首页导航与会话保留独立评审

日期：2026-11-03。范围：本轮 `App.tsx`、`Header.tsx`、`MetadataPanel.tsx`、`Viewport.tsx`、`WelcomeScreen.tsx`、`index.css` 及快捷键防护。评审方 `render_audit` 只读实现，未修改代码。

## 发现与处置

**HN-01（P2，已修复）：首页覆盖层未阻止后台全局快捷键。** 初版只使用 `inert={homeOpen}`。`Viewport`、`MprWorkspace`、`SplitWorkspace` 保持挂载，其 `window.keydown` 仍接收首页事件；方向键、预设数字键和 R 可改变被覆盖的阅片会话。`inert` 不会注销 window 监听，因此不能单独承担全局快捷键隔离。

实现方采纳：首页覆盖层增加 `data-viewer-home="true"`，统一 `blocksViewerShortcut` 检查该标记。复核上述三个工作区的阅片快捷键均先经过此检查；工具栏首页期间卸载。HN-01 的代码路径已关闭。真实首页按键后继续阅片的层号/VOI不变仍应在界面验收中确认，不能由本次静态审查代替。
