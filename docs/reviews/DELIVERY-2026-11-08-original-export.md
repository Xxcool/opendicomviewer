# 原始 DICOM 导出交付记录

日期：2026-11-08。实现与独立审查于11月5日完成，本次补原生保存及重新导入验收。

## 当前范围

`SeriesHandle.originalCandidates()` 直接返回导入来源，不从解码像素重编码。任意多帧位置的“当前原始实例”保存全部帧；序列按原始文件去重。Web 单实例 `.dcm`、多实例无压缩 ZIP32；原生按已授权文件 ID 复制，不接收任意源路径，也不经 IPC 传输大二进制。

单文件先在同目录临时文件写完、检查大小并同步，再 hard-link 无覆盖发布；已有目标和源目标相同均拒绝覆盖。序列创建独占的新子目录，正常复制失败清理本次输出。导出不清除标注 dirty，不修改原始文件，不包含新增标注，不宣称脱敏。

## 实际桌面验收

1. 系统文件夹选择器打开仓库 `sample-dicom/brain-head-mr`，选中193帧轴位序列。
2. 当前原始实例通过原生保存框另存到 `/private/tmp/odv-final-export-20261108/odv-original-instance.dcm`，界面显示“原始 DICOM 已保存”。Python 读取与 `head-axial-000.dcm` 完整比较：89630字节、完全一致，SHA-256 `8d21b1fe0f97a2da709137ace8fdcdc51fe02f6d2d7e8e480a1c81b024788e46`。
3. 当前序列保存到新子目录，共193实例。逐文件 SHA-256 集合与源193个轴位文件相同；以原生目录选择器重新导入输出目录，界面显示193帧、1/193。

## 未覆盖与限制

- 原生 ZIP 展开项与内置示例没有可直接复制的授权磁盘文件，明确拒绝；Web可从对应候选读取。用户可先解压再原生导入。
- 原生支持保存对话框取消；复制开始后尚不支持任务级取消。序列不承诺进程崩溃事务，强行退出可能留下部分完整实例或临时文件；未覆盖磁盘耗尽/断电实测。
- Web ZIP需要持有导出批次的字节，ZIP32上限不是设备内存预算；大序列内存及实际浏览器下载仍待验收。
- Windows原生文件保存仍需目标系统运行验证，不能从macOS成功推定通过。PNG原生保存由后续独立增量验证，本记录不替它背书。
