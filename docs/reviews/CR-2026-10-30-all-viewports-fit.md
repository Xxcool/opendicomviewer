# 全视口适配与完整缩略图

日期：2026-10-30。

## 范围及原因

上次仅补了 Stack 首帧适配。MPR 体积载入前没有统一同步画布尺寸，复用视口切换布局时保留旧相机；缩略图虽已有 contain，却没有内边距，原采样公式还会遗漏末端几行/列。

本次处理 Stack 和 MPR 三个方向的完整适配，以及序列缩略图边界。未实现通用独立分屏：当前 `viewport-layouts.ts` 的 2×2 / 1+3 明确是一个 Stack 加三个 Orthographic MPR。单层影像可以用于普通分屏，但不能重建出真实三向切面；不能把现有 MPR 布局宣传成所有影像通用的多视口。

## 修改与依据

- `Cs3dViewportAdapter.resetCamera()` 使用当前安装的 CS3D 4.22.13 `resetCamera({resetToCenter:false})`，居中当前切面而非跳回体积中层，再设原生 fit 基准的 0.9 倍缩放留边。已核对本机 `VolumeViewport.resetCamera` 和 `Viewport._getFocalPointForResetCamera`：该选项保留焦点沿切面法向的投影。
- `CornerstoneRenderer` 在体积载入前同步尺寸，布局切换后适配所有已载入的格子。记录自动适配模式；尺寸变化时自动模式重新适配，手动缩放/平移后保留相机，点击适应窗口恢复。销毁视口同步清理标记。
- `MprWorkspace` 观察工作区尺寸变化，重新投影准星叠加层，不更改准星世界坐标、不在观察回调写 React state。
- `thumbnail.ts` 的首尾采样覆盖完整矩阵边界；52px 缩略图画布内添加 4px 黑色留边，保持 contain。
- 设计说明、token 和原型同步更新。原始 DICOM、灰度换算、几何校验、MPR 数据构建及依赖未改动。
