# 加载人像内框独立复核

日期：2026-11-05。范围仅ImportProgressDialog的共同扫描窗口结构和对应CSS；只读审查，不改实现、不新增行为测试、不操作GUI。主线另跑构建和实际显示验收。

## 结论

当前结构将img、网格和扫描光带放入同一个`.import-scan-window`，该窗口position:relative、overflow:hidden并实际绘制内框边界。图片不再按外侧scan卡片的固定高度独立定位，因此原先“图片头顶与网格框不同参考区域”的路径已消除。

- img的width/height均为窗口100%，padding12px、border-box和object-fit:contain保证整幅图片按比例放在内框的内容范围，并保留上下内距；不再依赖图片原始头顶位置对齐外侧框。
- grid绝对定位inset0，beam的left/right/top均为0，定位参照都是同一窗口。即便阴影或端点存在亚像素/边框差异，窗口overflow会裁剪，不能画到内框外。
- 默认窗口高度274px；宽度≤560px统一降为222px。图片仍为同一窗口100%，光带动画终点与reduced-motion静态中点均使用同一个--scan-height，未留下原先292/240px图高与独立扫描终点造成的错位。
- caption位于扫描窗口外，作为scan卡片的另一子元素，不被图像和光带覆盖；装饰容器原有aria-hidden/空alt不变，没有改变进度或取消业务链。

常规桌面及现有窄屏规则下，未发现能够让人像实际越出共同内框的确认缺陷。该结论是DOM/CSS边界复核，不等于已经独立查看各设备实际排版。极窄/极低浏览器窗口下整个模态的可见性仍沿用原布局边界，不在本次人像局部修正中宣称已全面验收。
