## 核对结果

- `MeasurementSession` 先校验/复制后提交；非法记录、重复 ID 与不存在的更新不会改变历史。输入与返回的控制点、统计和快照深复制/冻结，避免调用方改写撤销历史。
- 新内容在当前 cursor 后截断重做分支；相同内容、删除不存在 ID、清空不存在序列为 no-op。保存点比较实际内容，撤销或重新构造相同内容能够恢复 clean；`markSaved()` 在 dirty 变化时广播，重复保存不广播。
- 通知期间拒绝内容/工具重入，所有当前订阅方接收同一版本；新增订阅在下一轮生效，取消各自独立。监听器异常不阻止其他订阅方接收已提交版本，交给构造函数显式错误回调。宿主应保证错误回调自身可靠，不把通知失败当成内容未提交。
- 坐标映射符合当前契约：第一组 IOP 乘像素列方向 x，第二组乘行方向 y；PixelSpacing 为 row/column。逆变换求实际基底 Gram 矩阵，覆盖四位小数舍入方向余弦，未以放宽切面容差掩盖误差。
- 缺失几何/间距、非有限输入、非正间距、非近似单位正交方向返回 null；其他切面残差大于 0.001 mm 的点不被静默投影。
- 两个测试文件直接导入被测实现；非轴位已知物理点、各向异性间距、斜切与舍入 IOP 往返、失败原子性和状态分支均有对应断言。

## 未覆盖与后续约束

这不是测量工具界面或持久化评审。像素是否处于图像矩阵内、源 SOP/帧引用、坐标空间声明、真实标定可信度、工具特定控制点数量/统计值由后续调用边界明确，不能仅凭这两个模块宣称这些已验收。仅按当前 TypeScript 领域契约审查，不将未经解析校验的外部 JSON 当作合法 MeasurementRecord。
