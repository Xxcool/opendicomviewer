# DICOM 结果互操作验收 · 2026-11-17

使用仓库内的公开单层 CT、macOS 桌面保存对话框导出的 Enhanced SR 和 GSPS，以及带已知坐标和中文备注的对照结果。整个传输在本机回环接口完成。

| 独立验证端 | 操作 | 实测结果 |
| --- | --- | --- |
| pynetdicom 3.0.4 的 SQLite 查询检索服务 qrscp | 对 CT 和一组对照结果运行 C-STORE、Study Root C-FIND 和 C-GET | 三次存储均返回成功。查出 CT、PR、SR 三个不同系列，按检查检索返回三个实例，失败、警告均为零。 |

| pydicom 3.0.2 | 独立核对回传对象与对照数据 | CT 像素字节保持一致。GSPS 系列引用和局部图形引用、SR 证据序列和坐标引用均指向同一 CT 的系列及实例。SR 和 PR 中的两个像素坐标完全一致；SR 保留 13.51562 mm 和中文备注。 |

DCMTK 位图验证覆盖呈现状态解析和窗值的显示效果。该工具在原始 400/40 窗值下输出的像素与只载入源 CT 相同，图形覆盖层位置由独立解码的顶点验证。商业工作站内呈现和医院 PACS 联调仍需相应环境。

## 复验步骤

在公开 CT 的桌面阅片页面绘制测距，保持源帧打开，导出测距 SR 与 GSPS。将源实例及两份结果分别存为临时目录中的 `source.dcm`、`sr.dcm`、`pr.dcm`。在该目录建立 Python 虚拟环境，安装 `pynetdicom==3.0.4`、`pydicom==3.0.2` 和 `SQLAlchemy==2.1.9`。激活虚拟环境后运行下列命令。

```sh
mkdir -p instances retrieved
qrscp -ba 127.0.0.1 --port 31112 --database-location "$PWD/index.db" --instance-location "$PWD/instances"
```

在第二个终端进入同一临时目录并激活同一环境。

```sh
storescu -v -aec QRSCP 127.0.0.1 31112 source.dcm sr.dcm pr.dcm
study_uid=$(python -c "import pydicom; print(pydicom.dcmread('source.dcm').StudyInstanceUID)")
findscu -v -aec QRSCP -S -k QueryRetrieveLevel=SERIES -k StudyInstanceUID="$study_uid" -k SeriesInstanceUID -k Modality 127.0.0.1 31112
getscu -v -aec QRSCP -S -od retrieved -k QueryRetrieveLevel=STUDY -k StudyInstanceUID="$study_uid" 127.0.0.1 31112
```

使用 pydicom 的 `Modality` 和 `SOPInstanceUID` 在 retrieved 中区分源图像和结果。将回传的 SR 与 PR 分别传给 `dsr2html <SR> result.html` 和 `dcmpschk <PR>`，再用 `dcmp2pgm -p <PR> source.dcm result.pgm` 验证应用呈现状态后的像素。回到应用，通过结果读回入口匹配同一源帧。[pynetdicom 查询检索服务](https://pydicom.github.io/pynetdicom/stable/apps/qrscp.html) · [DCMTK 命令参考](https://support.dcmtk.org/docs/)

## 本次修复及回归样本

查询检索服务按协商语法回传 Implicit VR Little Endian。读回器现能按 DICOM 数据字典读取隐式 VR 的坐标和文字锚点，并继续检查显式 VR 的文件类型和长度。另修复了第三方 GSPS 可以整体省略空间变换模块时的读回；没有这组字段时按原方向显示，单独缺少旋转或翻转时报告错误。[DICOM PS3.3 表 A.33.1-1](https://dicom.nema.org/medical/dicom/2026a/output/chtml/part03/sect_A.33.html)

`packages/adapters/source-local/testing/fixtures/exchange/` 的两份小型文件使用项目的全合成 CT 测试输入生成，再由独立的 pydicom 以隐式 VR 重写。输入像素间距为 2 × 0.5 mm，直线从 (0,0) 到 (4,0)，预期长度 2 mm。PR 对照省略旋转和翻转模块，还包含 (1,1) 处的文字锚点。运行 `pnpm exec vitest run packages/adapters/source-local/tests/gsps-roundtrip.test.ts` 可重复验证。

在修复版线上网页载入内置 CT，从「导出 → 标注 DICOM → 读取结果文件」打开归档返回的两份桌面结果。实际加入可编辑标注列表的直线显示为 78.57 mm。对同一 PR 将呈现极性从 IDENTITY 改为 INVERSE，核对图同一背景像素从 0 变为 255。公开样本的 Weasis 图形界面结果见[独立查看器验收](NATIVE-SAVE-2026-11-17.md)。
