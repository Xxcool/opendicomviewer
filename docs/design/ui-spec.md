# UI 规格表（v1 · 2026-10-28）

> **用途**：把界面从"照着线框即兴发挥"变成可逐项验收的清单。
> 每个元素都必须回答四个问题：**数据从哪来 / 缺失时显示什么 / 用什么状态色 / 文案是什么**。
> 答不上来的元素不许进代码。评审时按本表逐行打勾。

视觉基线：`prototype.html` · 数值来源：`tokens.md`

---

## 0. 通用规则

| 规则 | 内容 |
| --- | --- |
| 缺数据不空白 | 任何字段取不到时显示 `—` 或明确的"未知/未提供"，**禁止留白**（留白无法区分"没有"和"没加载"） |
| 不猜 | 禁绝对默认值兜底（如 IPP 缺失时填 `[0,0,0]`）。几何缺失必须显示 `几何缺失` 告警 |
| 数值等宽 | 所有数字（层数、WW/WL、测量值、帧数）用 `font-mono` + `tabular-nums` |
| 单位不省 | 物理量带单位：`1.0 mm`、`8.2 mm`、`−720 HU`；纯计数不带单位 |
| 颜色唯一 | 同一状态在所有位置用同一语义色（见 `tokens.md` §3.1） |

## 2. 左栏：序列列表

| 元素 | 数据来源 | 缺失/异常表现 | 状态色 | 文案 |
| --- | --- | --- | --- | --- |
| 标题与计数 | `listSeries().length` | `0` 时显示空态 | `--text-secondary` | `序列列表` + 数字 |
| 序列标题 | `SeriesSummary.modality` + `seriesDescription` | `seriesDescription` 为空 → 用 `第 N 序列`；`seriesNumber` 缺失不显示 | `--text-primary` | `CT · 胸部平扫` |
| 重建信息 | `ImagePlane.sliceThickness` / `spacing` | 缺失 → 省略该行（不留 `—`，因为是次要信息） | `--text-muted` | `1.0 mm` |
| 帧数 | `SeriesSummary.numberOfFrames` | — | `--text-secondary` | `1024 帧` |
| **告警徽标** | `SeriesHandle.warnings` 中的 `SLICE_GAP` / `IRREGULAR_SPACING` / `MISSING_GEOMETRY` | 无告警则不显示徽标 | `--color-warn` | 见 §6 映射表 |
| 选中态 | store `activeSeriesUid` | — | `--bg-active` + 左侧 `--accent` 竖条 | — |
| 空态 | — | `studies.length === 0` | `--text-muted` | `尚未载入影像。拖入文件夹、点击「打开文件夹」，或先用「载入示例」看看效果。` |

**多 study 分组（2026-10-28 补）**

一次导入常含多个 Study（示例数据就是 MR + CT 两个）。规则：

| 规则 | 内容 |
| --- | --- |
| 列出范围 | **列出全部 Study 的序列**，不按当前激活 Study 过滤——否则另一个 Study 的序列根本看不到，等于无法切换 |
| 分组标题 | Study 数 > 1 时显示：`studyDescription` + `studyDate`（YYYY-MM-DD）；只有 1 个 Study 时省略标题，避免噪音 |
| 点击 | 仍以序列为单位切换；切换后 `activeStudyUid` 跟随更新，右栏影像信息随之刷新 |

> 早期实现按 `activeStudyUid` 过滤，导致示例里的 CT 序列在左栏"消失"，用户以为只导入了 MR。

**列表项交互（2026-10-28 补，起因：用户反馈"左侧列表点不动"）**

| 场景 | 行为 | 视觉反馈 |
| --- | --- | --- |
| 点击未选中的序列 | `openSeries()` → 装载 → 切换视口 | 点击项立即进入 `切换中`（`opacity .55` + 禁用重复点击），成功后高亮为选中 |
| **点击已选中的序列** | **不重复装载**，但必须给反馈 | 该项 **320ms 呼吸高亮**（`ring` / `pulse`）。**禁止静默 return** |
| 装载失败 | 顶部红条显示原因（如压缩语法不支持） | 选中态**保持不变**，不留半切换状态 |
| 列表只有 1 条序列 | 允许点击（反馈同"已选中"） | 同时右栏或空态提示"当前仅 1 个序列" |
| 切换中再次点击其它序列 | 忽略，等当前切换结束 | 被点项无反应但不报错 |

> 判断标准很简单：**用户点下去，界面上必须有东西动一下**。没有反馈的点击等于 bug。

> **徽标必须在列表项里**，不能只放在视口顶部——用户是先在列表里挑序列的。

## 3. 视口

### 3.1 顶部状态条

| 元素 | 数据来源 | 缺失表现 | 状态色 | 文案 |
| --- | --- | --- | --- | --- |
| 视图类型 | 固定轴向（Phase 1） | — | `--text-primary` | `横断面 (Axial)` |
| 当前窗预设 | 上次 `setVOI` 的来源（手调时显示 `自定义`） | 从未设过 → `默认` | `--accent` 边框 | `肺窗` / `自定义` |
| 层数 | `setStackIndex` 的索引 + `meta.planes.length` | — | `--text-secondary` | `层数 512/1024` |
| WW / WL | `RendererPort.getVOI()`（`whenIdle` 之后读，避免读到旧帧） | 首帧未就绪 → `—` | `--text-secondary` | `WW 1500 · WL −600` |
| 复位 | — | — | 次级 | `复位` |

### 3.2 画布叠加层（Overlay）

**四角信息按优先级分配，任何一角最多 2 行**（多了会被图像吞掉）：

| 位置 | 内容 | 数据来源 | 缺失表现 |
| --- | --- | --- | --- |
| 左上 | 隐私状态 + Modality | 见 §7 | 未知时 `未脱敏`（保守） |
| 右上 | 层厚、KVP/mAs（存在才显示） | `ImagePlane.sliceThickness`、标签取值 | 整行省略 |
| 左下 | 当前窗（WW/WL 与预设名） | `getVOI()` | `—` |
| 右下 | 物理位置（`IPP` 沿法向投影值）、层间距 | `ImagePlane.imagePositionPatient` + `spacing` | `几何缺失`（`--color-warn`） |

| 元素 | 规则 |
| --- | --- |
| 方位标记 | 轴位固定 上 `A` / 下 `P` / 左 `R` / 右 `L`（放射学惯例：图像左侧为患者右侧）。非轴位时四个字母按 IOP 计算，且顶部加 `非轴位` 徽标 |
| 比例尺 | 由 `pixelSpacing` 与当前缩放换算，取 1-2-5 系列整数长度（5/10/20/50 mm），标签带单位；`pixelSpacing` 缺失时不画比例尺并显示 `无物理标尺` |
| 文字可读性 | 白字 + `--overlay-scrim` 胶囊 + 投影，保证在任意灰度上可读；**字号不小于 11px** |
| 告警条 | 位于顶部居中，只显示最高优先级一条；多条时后缀 `+N`，点击展开 |

### 3.3 底部控制栏

**切片导航（2026-10-28 修订，取代原滑块）**

> 原设计是"1 ──●──── 1024"滑块。撤销理由：CT/MR 序列常见 200–1500 帧，
> 1024 帧时滑块 1 像素 ≈ 5 层，**物理上无法精确定位**；阅片习惯是滚轮微调 + 直接输入层号。
> 滑块只在**小序列**里才有意义。

| 元素 | 数据来源 | 缺失表现 | 行为 |
| --- | --- | --- | --- |
| 上一层 / 下一层 | 当前索引 | `planeCount <= 1` 时整组隐藏 | 点击 ±1；对应滚轮（`Shift+滚轮` ±10） |
| 层号输入框 | 当前索引 | — | 键入数字回车跳转，越界自动钳到 `[1, N]`；非法输入恢复原值 |
| `/ N` | `meta.planes.length` | — | 只读 |
| 进度条 | 当前索引 / N | `planeCount <= 1` 隐藏 | **只读**，2–3px 高，不响应拖动 |
| （例外）小序列滑块 | — | `planeCount <= 200` 时，进度条**升级为可拖动滑块** | 200 帧以内拖动精度可接受 |

**窗口预设：按部位分组，不写死五个**

| 元素 | 数据来源 | 缺失表现 |
| --- | --- | --- |
| 部位选择器 | `(0018,0015) BodyPartExamined` 归一到 `胸部/头颅/腹部/四肢/脊柱/未识别` | 标签缺失 → `未识别`，只给通用预设组 |
| `自动` 预设（永远第一） | `(0028,1050)/(0028,1051)` → 缺失则用像素直方图 2%–98% 分位推算 | 都拿不到 → 用 `min/max`，并标注 `自动（估算）` |
| 部位预设组 | `WINDOW_PRESETS_BY_BODYPART`（core） | 组内最多显示 3 个高频项，其余进 `更多 ▾` |
| 当前预设高亮 | 与 `getVOI()` 比对 | 手调后全部不高亮，顶栏显示 `自定义` |

预设集（首版）：

| 部位 | 预设项 |
| --- | --- |
| 胸部 | 肺 1500/−600 · 纵隔 350/40 · 骨 2000/400 |
| 头颅 | 脑 80/40 · 骨 2000/400 · 卒中 30/30 |
| 腹部 | 腹 400/50 · 肝 150/30 · 骨 2000/400 |
| 四肢/骨关节 | 骨 2000/400 · 软组织 400/40 · 关节 1200/300 |
| 脊柱 | 骨 2000/400 · 软组织 400/40 · 椎间盘 500/50 |
| 未识别 | 骨 2000/400 · 软组织 400/40 · 肺 1500/−600 |

> **MR / CR / DX 不走 CT 窗值表**：MR 按序列描述匹配（T1/T2/FLAIR/STIR），
> CR/DX 默认 `自动` + `MONOCHROME1` 反转。Phase 2 接入。

**能力受限入口（2026-10-28 修订）**

| 规则 | 内容 |
| --- | --- |
| 位置 | **不放底栏**。底栏是高频操作区，不可用功能不该占位；统一收到右栏「能力与降级」 |
| 形态 | 可点击的下划线链接：`不可用 · 查看原因`（**不是 `disabled` 按钮**） |
| 点击 | 就地展开原因（缺哪条通路、GPU 不满足哪项、属于哪个 Phase），`aria-expanded` 同步 |
| 理由 | `disabled` + tooltip 的问题：触屏没有 hover，用户点了没反应会以为程序坏了 |

> 四肢/长骨还额外需要提示：**轴向浏览对长骨价值有限**，建议等 Phase 2 的 MPR；
> 该提示出现在右栏能力区，不在视口里打断浏览。

## 4. 右栏

| 分区 | 元素 | 数据来源 | 缺失表现 | 状态色 |
| --- | --- | --- | --- | --- |
| 影像信息 | 患者 / 检查 / 日期 / 设备 | `StudyMeta.patientName`、`studyDescription`、`studyDate`、标签 | `—` | 隐私状态见 §7 |
| 当前序列 | Modality / 切片数 / 矩阵 / 像素间距 / 层间距 | `SeriesMeta`、`ImagePlane` | `—`；层间距异常时整行 `--color-warn` | — |
| 测量与工具 | 当前工具 / 直线 / ROI 均值 / ROI 标准差 | `MeasurementRecord`（见 ADR-014） | 无测量时显示 `尚未添加测量` | 数值 `--text-primary` |
| 免责提示 | 静态（R10） | — | — | `⚠ 测量值仅供参考，不构成诊断依据。`（`--color-warn`） |
| 能力与降级 | 后端 / GPU / 体绘制 / MPR | `capabilities()` + 启动探测 | 不可用项写 `不可用 · 已隐藏入口` | `--color-disabled` |

> 右栏是"当前状态的解释面板"：用户看完图会来这里确认"我看到的数字是什么"。
> 因此这里的每个值都必须能追到一个字段，不许出现汇编出来的估算值。

## 5. 全局状态

| 状态 | 触发 | 表现 | 可取消 |
| --- | --- | --- | --- |
| 首屏骨架 | 应用启动 | 骨架屏（顶栏 + 三栏轮廓）**< 300ms 出现**，不出现纯白/纯黑空白 | — |
| 导入中 | `probe()` 进行中 | 模态：已扫描 n/N 文件、已识别 x 个序列、进度条 | **必须**（`AbortController`） |
| 部分失败 | `probe()` 有失败项 | 模态：`成功 n · 失败 m`，逐项列文件名 + 原因，主按钮 `仅载入成功的 n 个` | — |
| 导入失败 | 全失败/异常 | 顶栏红色条 + 可关闭 | — |
| 渲染初始化失败 | `mount()` 抛错 | 顶栏红色条：`渲染引擎初始化失败: <原因>`；**禁止只写 console** | — |
| 能力不支持 | `capabilities()` | 右栏「能力与降级」给出 `不可用 · 查看原因`，点击就地展开原因；**底栏不放占位** | — |

## 6. 告警码 → 文案映射（`DataWarning.code`）

### 6.1 严重度分档（2026-10-28 修订）

真实 MR 数据（36 层、7 处层间距跳跃、7° 斜切）首次接入后，界面一次冒出 10 条同色告警，
把"影像信息"挤出屏幕，用户直接忽略——**告警全部同色同权，等于没有告警**。

| severity | 含义 | 颜色 | 展示 |
| --- | --- | --- | --- |
| `info` | 值得知道但不影响当前操作 | `--color-info`（灰蓝） | 右栏清单，措辞明确写"不影响…" |
| `warning` | 可能影响判读精度，需知情 | `--color-warn`（琥珀） | 右栏 + 视口顶条（取最高级一条） |
| `error` | 数据不可用或被剔除 | `--color-danger`（红） | 同上，且优先展示 |

两条呈现规则：
1. **同类聚合**：`SLICE_GAP` / `IRREGULAR_SPACING` 多处发生时只报一条，
   消息里带"N 处、最大 X mm、按基准估算缺约 M 层"，逐处索引放进 `details.gaps` 供展开；
2. **顶条只显示最高级一条**，其余以"另有 N 条见右侧"提示，禁止把所有消息拼成一行。

### 6.2 映射表

| code | severity | 列表徽标 | 视口告警条 | 颜色 |
| --- | --- | --- | --- | --- |
| `SLICE_GAP` | `warning` | `⚠ 缺 N 层` | `检测到 N 处层缺失（层间距 1.0 → 2.0 mm），测量结果可能受影响` | `--color-warn` |
| `IRREGULAR_SPACING` | `warning` | `⚠ 层距异常` | `层间距不均匀（最小 0.8 / 最大 2.0 mm）` | `--color-warn` |
| `DUPLICATE_SLICE` | `warning` | `⚠ 重复切片` | `检测到 N 张位置重复的切片，已按 SOPInstanceUID 去重` | `--color-warn` |
| `ORIENTATION_MISMATCH` | `error` | `⚠ 朝向不一致` | `N 张切片朝向与主序列不同，已排除（可在列表中单独查看）` | `--color-warn` |
| `NON_AXIAL_ORIENTATION` | `info`（>15° 升为 `warning`） | `⚠ 非轴位` | `该序列非标准轴位，轴向浏览与测量需谨慎` | `--color-warn` |
| `MISSING_GEOMETRY` | `warning` | `⚠ 几何缺失` | `切片缺少位置/朝向信息，无法保证层序与测量精度` | `--color-warn` |
| `BURNED_IN_INFO` | `warning` | `⚠ 烧录信息` | `图像中疑似含烧录文字，脱敏无法覆盖像素内容` | `--color-warn` |
| `UNSUPPORTED_TRANSFER_SYNTAX` | `error` | `⚠ 格式不支持` | `压缩传输语法 <UID> 暂不支持，该文件未载入` | `--color-danger` |
| `DECODE_PARTIAL_FAILURE` | `error` | `⚠ 部分帧失败` | `N 帧解码失败，其余可正常浏览` | `--color-danger` |

> 新增 `DataWarning.code` 必须同时更新本表，否则该告警在界面上无处显示。

## 7. 隐私状态（本项目的差异点，必须常显）

| 状态 | 判定 | 显示位置 | 颜色 | 文案 |
| --- | --- | --- | --- | --- |
| 已匿名 | `PS3.15` 白名单字段全部为空/伪名，且 UID 已重映射 | 视口左上角 + 右栏"患者"行 | `--color-ok` | `已匿名 · 数据未出本机` |
| 未脱敏 | 存在真实患者姓名/ID/日期等标识 | 同上，并在右栏展开一行说明 | `--color-warn` | 角标 `含身份信息`；右栏 `⚠ 该文件仍含原始身份信息，导出前请使用「脱敏导出」` |
| 未知 | 尚未解析完成 | 同上 | `--text-muted` | `隐私状态未知` |

**关于内置示例数据**：`sample-dicom/` 下是公开测试数据集（PatientName 为 `Dummy`、
`MISTER^CT`），**不是真实患者**。按上面的保守默认，界面仍会显示"含身份信息"——
这是**预期行为**（宁可误报也不误判为安全），不要为此加特例白名单。

**硬要求**：只要打开了真实患者数据，界面上必须能一眼看到"当前未脱敏"。
这是本项目"可验证零回传"承诺在视觉层的兑现——不能只写在 README 里。

## 8. 键盘与指针（与 `ARCHITECTURE §10.2` 对齐）

| 输入 | 行为 | 冲突规则 |
| --- | --- | --- |
| 左键拖动 | 当前激活工具（默认：无工具时只做定位，不画） | — |
| **Shift + 左键拖动** | 调窗（WW/WL） | **工具激活时依然生效**，保证任何状态下都能调窗 |
| 右键拖动 | 调窗 | 与上一条等价，为三键鼠标提供 |
| 滚轮 | 切片翻页（步长 1，`Shift+滚轮` 步长 10） | 视口有焦点时不滚动页面 |
| 空格 + 左键 / 中键 | 平移 | 优先于工具 |
| `1`–`5` | 预设窗 | 输入框聚焦时不触发 |
| `R` / `Shift+R` | 复位视图 / 复位全部 | — |
| `Esc` | 取消当前操作（画到一半的测量、打开的弹层） | — |
| `Ctrl/⌘ + K` | 命令面板 | — |

> **ADR-014 落地前提**：左键的工具语义与"左键什么也不做"的默认态必须显式定义，
> 否则用户第一次点击会以为程序没反应。
