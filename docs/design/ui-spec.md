# UI 规格表（v1 · 2026-10-28）

> **用途**：把界面从"照着线框即兴发挥"变成可逐项验收的清单。
> 每个元素都必须回答四个问题：**数据从哪来 / 缺失时显示什么 / 用什么状态色 / 文案是什么**。

## 工作区 v2（2026-10-29，覆盖下文旧布局口径）

### 欢迎页修订（2026-10-30）

顶部与主入口二次对齐用户裁图：顶栏高 50px，左侧为打开文件夹、打开文件、分隔线及书本图标示例；右侧为齿轮设置、分隔线及当前主题下拉。文件夹采用打开状态的填充图形，文件采用折角填充图形；欢迎页按钮复用同一文件夹 SVG。主题下拉提供深色/浅色两个真实选项，支持键盘、Esc 与点击外部关闭。
欢迎页取消整页垂直居中，主内容距顶栏下方 86px；标题 40px/54px，标题后留 18px，说明 22px/33px；说明后留 36px，主按钮 294×60px、圆角 10px、字体 20px、文件夹图标 24px。短窗仍使用滚动容器；窄窗缩小标题与说明，按钮宽度不超过可用空间。

按用户提供的参考图调整为居中导入页：标题「打开本地影像」、本机处理说明、打开文件夹主按钮、两张真实示例影像卡片、文件拖放区、三步操作说明。
示例封面按用户第二张参考图调整：MR 采用具有头部轮廓的矢状面，CT 采用可见胸廓的横断面；直接使用用户在会话中提供的参考图，文件保持原样，以 CSS 定位展示两处影像区域，随应用离线打包。封面只表示影像类型，不能声称与预置 DICOM 是同一患者或同一切片；卡片下方折叠说明提供预置样本内容和用户参考图来源。
卡片分别只显示「MR 脑部影像」「CT 胸腹影像」，采用约 174px 宽、154px 影像区、38px 标题栏、30px 间距的构图。完整容纳头部/胸廓轮廓，不裁切解剖边缘。原始示例仍为 MR 36 帧、CT 单层，不宣称完整 MPR 演示。
拖放区只宣称当前支持的 DICOM 文件和 ZIP，文件夹通过主按钮选择；点击拖放区打开文件选择器，键盘同样可达。使用步骤为「打开影像 → 浏览序列 → 调整视图」。
桌面内容最大宽度 760px；窄窗允许纵向滚动，示例卡片保持双列，三步说明在窄窗下纵向排列。沿用系统字体、既有主题和蓝色主按钮。

### 脑部示例数据修订（2026-10-30）

脑部入口载入同一 McGill ICBM152 平均头部 T1 模板派生的 193 层连续轴位序列及一张中线矢状面参考图；首选 193 层序列，用于 2×2 / 1+3、MPR 十字准星和翻层联动。保留原始体素值、灰度缩放和物理几何，标明 DERIVED/SECONDARY 与教学模板来源；不是对参考截图的 DICOM 包装。原 36 帧 MR 序列保留为浏览示例，但其网格不连续，不能宣称支持 MPR。
脑部卡片使用同一模板中线 DICOM 生成的预览；CT 卡片仍为示意封面。卡片下方常显「MR：193 层，支持 2×2 / MPR 联动；CT：单层浏览」，折叠说明介绍矢状面参考图与来源。切换到单层参考图时仍正确限制 MPR。影像详情「空间重建」显示可进入 2×2 / 1+3 的说明；不能重建时以「MPR 不可用 · 查看原因」展开真实数据或后端限制，不能无理由消失。视口切面名与四边方位由有效 IOP 计算；矢状面显示 S/I/A/P，不能再固定写轴位 A/P/R/L。斜切或几何未知时不猜方向；物理位置以法向距离表示，不固定标为 Z。

- 顶栏负责打开文件夹、打开文件、示例、设置和主题；浏览器不常驻「读光盘」占位按钮。
- 阅片工具条负责翻页/调窗/平移/缩放、放大/缩小/适应窗口、MPR 布局、序列面板、影像详情、专注模式。
- 新序列首帧载入完成后按当前画布尺寸适应窗口；「适应窗口」先同步画布尺寸再复位相机，不改变窗宽窗位。逐层翻页保留用户缩放和平移。Stack 的 GPU 显示缓冲使用已应用 Modality LUT / Rescale 的强度，不能拿原始 int16 值直接套物理窗；原始 PixelFrame 仍保留供数据计算使用。
- 工具选择存于 Zustand，VOI、平移与缩放仍以渲染器为真源。右键和 Shift+左键始终调窗，中键始终平移；高频指针移动仅调用端口和写 DOM。
- 滚轮翻页；左键按当前工具操作。MPR 固定灰度的切面不开放调窗，工具条提示原因；平移/缩放作用于当前激活视口。
- 已载入时左栏默认展开（224px），右栏默认收起（288px）；空态不显示空元数据。面板可独立收起，专注模式同时隐藏两侧，再次点击恢复此前面板状态。切换不重建渲染器。
- 右侧详情分「影像」「提醒」两个页签，提醒显示数量。未实现的测量不作为占位分区；渲染后端与能力说明进入影像详情的折叠区。
- 空态给出打开文件夹、查看 MR/CT 示例和操作指南；明确文件在本机处理。示例不承诺全部可 MPR，失败原因仍可查询。
- 序列列表按可见项懒加载中间帧缩略图；最多 2 项并发，使用独立句柄，完成或卸载时释放。缩略图失败显示模态和「预览不可用」，不改变该序列能否打开。
- 布局与工具切换使用真实按钮及 aria-pressed；侧栏开关使用 aria-expanded/aria-controls；可见焦点环常驻规范。
- 初始左键为翻页。快捷键 B/W/P/Z 选择工具，F 切换专注模式；输入框、文本域、可编辑区域及模态对话框内不触发工作区快捷键。
- 桌面窄窗保留工具图标与可访问名称；底部预设可横向滚动，1100px 以下隐藏进度滑块并保留层号输入与前后翻层。移动/触屏适配不在本轮范围。
- 窗口预设对 CT 展示既有预设，对其他模态仅提供默认窗；默认窗恢复当前序列初次装载窗口，不改变相机。

## 0. 通用规则

| 规则 | 内容 |
| --- | --- |
| 缺数据不空白 | 任何字段取不到时显示 `—` 或明确的"未知/未提供"，**禁止留白**（留白无法区分"没有"和"没加载"） |
| 不猜 | 禁绝对默认值兜底（如 IPP 缺失时填 `[0,0,0]`）。几何缺失必须显示 `几何缺失` 告警 |
| 数值等宽 | 所有数字（层数、WW/WL、测量值、帧数）用 `font-mono` + `tabular-nums` |
| 单位不省 | 物理量带单位：`1.0 mm`、`8.2 mm`、`−720 HU`；纯计数不带单位 |
| 颜色唯一 | 同一状态在所有位置用同一语义色（见 `tokens.md` §3.1） |

**多 study 分组（2026-10-28 补）**

一次导入常含多个 Study（示例数据就是 MR + CT 两个）。规则：

| 规则 | 内容 |
| --- | --- |
| 列出范围 | **列出全部 Study 的序列**，不按当前激活 Study 过滤——否则另一个 Study 的序列根本看不到，等于无法切换 |
| 分组标题 | Study 数 > 1 时显示：`studyDescription` + `studyDate`（YYYY-MM-DD）；只有 1 个 Study 时省略标题，避免噪音 |
| 点击 | 仍以序列为单位切换；切换后 `activeStudyUid` 跟随更新，右栏影像信息随之刷新 |

> 早期实现按 `activeStudyUid` 过滤，导致示例里的 CT 序列在左栏"消失"，用户以为只导入了 MR。

**列表项交互（2026-10-28 补，起因：用户反馈"左侧列表点不动"）**

| 场景 | 行为 | 视觉反馈 |
| --- | --- | --- |
| 点击未选中的序列 | `openSeries()` → 装载 → 切换视口 | 点击项立即进入 `切换中`（`opacity .55` + 禁用重复点击），成功后高亮为选中 |
| **点击已选中的序列** | **不重复装载**，但必须给反馈 | 该项 **320ms 呼吸高亮**（`ring` / `pulse`）。**禁止静默 return** |
| 装载失败 | 顶部红条显示原因（如压缩语法不支持） | 选中态**保持不变**，不留半切换状态 |
| 列表只有 1 条序列 | 允许点击（反馈同"已选中"） | 同时右栏或空态提示"当前仅 1 个序列" |
| 切换中再次点击其它序列 | 忽略，等当前切换结束 | 被点项无反应但不报错 |

> 判断标准很简单：**用户点下去，界面上必须有东西动一下**。没有反馈的点击等于 bug。

> **徽标必须在列表项里**，不能只放在视口顶部——用户是先在列表里挑序列的。

### 3.2 画布叠加层（Overlay）

**四角信息按优先级分配，任何一角最多 2 行**（多了会被图像吞掉）：

| 位置 | 内容 | 数据来源 | 缺失表现 |
| --- | --- | --- | --- |
| 左上 | 隐私状态 + Modality | 见 §7 | 未知时 `未脱敏`（保守） |
| 右上 | 层厚、KVP/mAs（存在才显示） | `ImagePlane.sliceThickness`、标签取值 | 整行省略 |
| 左下 | 当前窗（WW/WL 与预设名） | `getVOI()` | `—` |
| 右下 | 物理位置（`IPP` 沿法向投影值）、层间距 | `ImagePlane.imagePositionPatient` + `spacing` | `几何缺失`（`--color-warn`） |

| 元素 | 规则 |
| --- | --- |
| 方位标记 | 轴位固定 上 `A` / 下 `P` / 左 `R` / 右 `L`（放射学惯例：图像左侧为患者右侧）。非轴位时四个字母按 IOP 计算，且顶部加 `非轴位` 徽标 |
| 比例尺 | **固定在各视口左下角（不跟随鼠标）**，用画布中心两点反算 mm/px，取 1-2-5 系列（1/2/5/10/20/50/100/200/500 mm）；`1×1` 与每一格 MPR 都显示；装载完成、复位、宿主尺寸变化时重算 | `canvasToWorld` 抛错或物理信息缺失 → 显示 `无物理标尺`，不画刻度，不编造长度 |
| 文字可读性 | 白字 + `--overlay-scrim` 胶囊 + 投影，保证在任意灰度上可读；**字号不小于 11px** |
| 告警条 | 位于顶部居中，只显示最高优先级一条；多条时后缀 `+N`，点击展开 |

### 3.3 底部控制栏

**切片导航（2026-10-28 修订，取代原滑块）**

> 原设计是"1 ──●──── 1024"滑块。撤销理由：CT/MR 序列常见 200–1500 帧，
> 1024 帧时滑块 1 像素 ≈ 5 层，**物理上无法精确定位**；阅片习惯是滚轮微调 + 直接输入层号。
> 滑块只在**小序列**里才有意义。

| 元素 | 数据来源 | 缺失表现 | 行为 |
| --- | --- | --- | --- |
| 上一层 / 下一层 | 当前索引 | `planeCount <= 1` 时整组隐藏 | 点击 ±1；对应滚轮（`Shift+滚轮` ±10） |
| 层号输入框 | 当前索引 | — | 键入数字回车跳转，越界自动钳到 `[1, N]`；非法输入恢复原值 |
| `/ N` | `meta.planes.length` | — | 只读 |
| 进度条 | 当前索引 / N | `planeCount <= 1` 隐藏 | **只读**，2–3px 高，不响应拖动 |
| （例外）小序列滑块 | — | `planeCount <= 200` 时，进度条**升级为可拖动滑块** | 200 帧以内拖动精度可接受 |

**窗口预设：按部位分组，不写死五个**

| 元素 | 数据来源 | 缺失表现 |
| --- | --- | --- |
| 部位选择器 | `(0018,0015) BodyPartExamined` 归一到 `胸部/头颅/腹部/四肢/脊柱/未识别` | 标签缺失 → `未识别`，只给通用预设组 |
| `自动` 预设（永远第一） | `(0028,1050)/(0028,1051)` → 缺失则用像素直方图 2%–98% 分位推算 | 都拿不到 → 用 `min/max`，并标注 `自动（估算）` |
| 部位预设组 | `WINDOW_PRESETS_BY_BODYPART`（core） | 组内最多显示 3 个高频项，其余进 `更多 ▾` |
| 当前预设高亮 | 与 `getVOI()` 比对 | 手调后全部不高亮，顶栏显示 `自定义` |

| 部位 | 预设项 |

**能力受限入口（2026-10-28 修订）**

| 规则 | 内容 |
| --- | --- |
| 位置 | **不放底栏**。底栏是高频操作区，不可用功能不该占位；统一收到右栏「能力与降级」 |
| 形态 | 可点击的下划线链接：`不可用 · 查看原因`（**不是 `disabled` 按钮**） |
| 点击 | 就地展开原因（缺哪条通路、GPU 不满足哪项、属于哪个 Phase），`aria-expanded` 同步 |
| 理由 | `disabled` + tooltip 的问题：触屏没有 hover，用户点了没反应会以为程序坏了 |

> 四肢/长骨还额外需要提示：**轴向浏览对长骨价值有限**，建议等 Phase 2 的 MPR；
> 该提示出现在右栏能力区，不在视口里打断浏览。

### 3.4 多视口布局与 MPR（P3，2026-10-28）

**布局切换**（顶栏「视口布局」按钮组，仅 `supportsVolume === true` 时出现）

| 模式 | 内容 | 说明 |
| --- | --- | --- |
| `1×1` | 单视口轴位（STACK，全分辨率） | 默认；无体积通路也始终可用 |
| `2×2` | 左上全分辨率轴位 + 三格 MPR（Axial / Coronal / Sagittal） | 四格等分，2px 间隙 |
| `1+3` | 左大图轴位 + 右列三格 MPR 纵向排列 | 与 `2×2` 共用同一组视口 id，切布局不重建视口 |

- **无激活序列时整组按钮隐藏**：空态不允许切到 `2×2 / 1+3`，避免切出只有「请载入序列」的空壳 MPR。
- 切换请求串行化：最后一次点击一定最后生效，中间状态不得拆掉刚建好的视口。
- 体积在进入含 MPR 的布局后才构建；仅切布局不重复构建。
- 同一序列的体积在布局往返（如 `2×2 → 1×1 → 2×2`）后必须复用，不得重建或清空。

**MPR 格**

| 元素 | 规格 |
| --- | --- |
| 角标 | 左上角方向短名（`Axial` / `Coronal` / `Sagittal`），11px，胶囊底 |
| 显示区间 | 体积是 8-bit 降采样缓冲，VOI 固定 `0–255`（WW 255 · WL 127.5），**不跟随调窗**；调窗只作用于全分辨率轴位格 |
| 层号 | 各格独立计数：Axial 用 z、Coronal 用 y、Sagittal 用 x 维度 |
| 体积失败 | 该格覆盖错误态并显示 `MPR 体积构建失败：…`，同时顶栏横幅提示；**禁止黑屏或静默降级**（R7） |
| 不支持体积 | 布局按钮组整体隐藏（`supportsVolume !== true`），不给点了会报错的入口 |

**准星与联动**

| 规则 | 内容 |
| --- | --- |
| 初始位置 | 体积几何中心 |
| 滚轮/层号 | 任一格翻层 → 其余格把准星投影到同一世界坐标，层号随动 |
| 容差 | 单轴越界（准星在体积边缘）只影响该格，其余格照常定位，不弹错 |
| 绘制 | 各格用 `worldToCanvas` 投影，越界时该格隐藏准星 |
| 高频路径 | 滚轮导航串行化、命令式写 DOM；渲染循环内禁止 `setState`（R4） |

## 4. 右栏

| 分区 | 元素 | 数据来源 | 缺失表现 | 状态色 |
| --- | --- | --- | --- | --- |
| 影像信息 | 患者 / 检查 / 日期 / 设备 | `StudyMeta.patientName`、`studyDescription`、`studyDate`、标签 | `—` | 隐私状态见 §7 |
| 当前序列 | Modality / 切片数 / 矩阵 / 像素间距 / 层间距 | `SeriesMeta`、`ImagePlane` | `—`；层间距异常时整行 `--color-warn` | — |
| 测量与工具 | 当前工具 / 直线 / ROI 均值 / ROI 标准差 | `MeasurementRecord`（见 ADR-014） | 无测量时显示 `尚未添加测量` | 数值 `--text-primary` |
| 免责提示 | 静态（R10） | — | — | `⚠ 测量值仅供参考，不构成诊断依据。`（`--color-warn`） |
| 能力与降级 | 后端 / GPU / 体绘制 / MPR | `capabilities()` + 启动探测 | 不可用项写 `不可用 · 已隐藏入口` | `--color-disabled` |

**当前实现边界（2026-10-29 修正）**：
- 体积接口可用只代表具备 MPR 通路，不能据此显示「体绘制可用」；体绘制尚未实现，展示可展开的不可用原因。
- 未检测 GPU 类型时显示「类型未检测」，不能把默认 `isSoftwareFallback: false` 当作硬件加速证明。
- MPR 按当前序列的规则网格校验结果展示；不支持的序列隐藏布局入口，在能力区说明原因，保留原始切片浏览。
- 当前 MPR 尚未实现非均匀重采样及机架剪切校正；缺层、非均匀层距、平面偏移、逐层方向或像素间距变化必须在读像素前拒绝。

> 右栏是"当前状态的解释面板"：用户看完图会来这里确认"我看到的数字是什么"。
> 因此这里的每个值都必须能追到一个字段，不许出现汇编出来的估算值。

## 6. 告警码 → 文案映射（`DataWarning.code`）

### 6.1 严重度分档（2026-10-28 修订）

真实 MR 数据（36 层、7 处层间距跳跃、7° 斜切）首次接入后，界面一次冒出 10 条同色告警，
把"影像信息"挤出屏幕，用户直接忽略——**告警全部同色同权，等于没有告警**。

| severity | 含义 | 颜色 | 展示 |
| --- | --- | --- | --- |
| `info` | 值得知道但不影响当前操作 | `--color-info`（灰蓝） | 右栏清单，措辞明确写"不影响…" |
| `warning` | 可能影响判读精度，需知情 | `--color-warn`（琥珀） | 右栏 + 视口顶条（取最高级一条） |
| `error` | 数据不可用或被剔除 | `--color-danger`（红） | 同上，且优先展示 |

两条呈现规则：
1. **同类聚合**：`SLICE_GAP` / `IRREGULAR_SPACING` 多处发生时只报一条，
   消息里带"N 处、最大 X mm、按基准估算缺约 M 层"，逐处索引放进 `details.gaps` 供展开；
2. **顶条只显示最高级一条**，其余以"另有 N 条见右侧"提示，禁止把所有消息拼成一行。

### 6.2 映射表

| code | severity | 列表徽标 | 视口告警条 | 颜色 |
| --- | --- | --- | --- | --- |
| `SLICE_GAP` | `warning` | `⚠ 缺 N 层` | `检测到 N 处层缺失（层间距 1.0 → 2.0 mm），测量结果可能受影响` | `--color-warn` |
| `IRREGULAR_SPACING` | `warning` | `⚠ 层距异常` | `层间距不均匀（最小 0.8 / 最大 2.0 mm）` | `--color-warn` |
| `DUPLICATE_SLICE` | `warning` | `⚠ 重复切片` | `检测到 N 张位置重复的切片，已按 SOPInstanceUID 去重` | `--color-warn` |
| `ORIENTATION_MISMATCH` | `error` | `⚠ 朝向不一致` | `N 张切片朝向与主序列不同，已排除（可在列表中单独查看）` | `--color-warn` |
| `NON_AXIAL_ORIENTATION` | `info`（>15° 升为 `warning`） | `⚠ 非轴位` | `该序列非标准轴位，轴向浏览与测量需谨慎` | `--color-warn` |
| `MISSING_GEOMETRY` | `warning` | `⚠ 几何缺失` | `切片缺少位置/朝向信息，无法保证层序与测量精度` | `--color-warn` |
| `BURNED_IN_INFO` | `warning` | `⚠ 烧录信息` | `图像中疑似含烧录文字，脱敏无法覆盖像素内容` | `--color-warn` |
| `UNSUPPORTED_TRANSFER_SYNTAX` | `error` | `⚠ 格式不支持` | `压缩传输语法 <UID> 暂不支持，该文件未载入` | `--color-danger` |
| `DECODE_PARTIAL_FAILURE` | `error` | `⚠ 部分帧失败` | `N 帧解码失败，其余可正常浏览` | `--color-danger` |

> 新增 `DataWarning.code` 必须同时更新本表，否则该告警在界面上无处显示。

## 7. 隐私状态（本项目的差异点，必须常显）

| 状态 | 判定 | 显示位置 | 颜色 | 文案 |
| --- | --- | --- | --- | --- |
| 已匿名 | `PS3.15` 白名单字段全部为空/伪名，且 UID 已重映射 | 视口左上角 + 右栏"患者"行 | `--color-ok` | `已匿名 · 数据未出本机` |
| 未脱敏 | 存在真实患者姓名/ID/日期等标识 | 同上，并在右栏展开一行说明 | `--color-warn` | 角标 `含身份信息`；右栏 `⚠ 该文件仍含原始身份信息，导出前请使用「脱敏导出」` |
| 未知 | 尚未解析完成 | 同上 | `--text-muted` | `隐私状态未知` |

**关于内置示例数据**：`sample-dicom/` 下是公开测试数据集（PatientName 为 `Dummy`、
`MISTER^CT`），**不是真实患者**。按上面的保守默认，界面仍会显示"含身份信息"——
这是**预期行为**（宁可误报也不误判为安全），不要为此加特例白名单。

**硬要求**：只要打开了真实患者数据，界面上必须能一眼看到"当前未脱敏"。
这是本项目"可验证零回传"承诺在视觉层的兑现——不能只写在 README 里。

### 全视口适配修正（2026-10-30）

Stack 与 MPR 三个方向均按各自当前尺寸完整适配，默认影像占适配尺寸的 90%，四周留黑边。载入、布局切换和自动适配状态下的尺寸变化均重新适配；用户缩放或平移后保留手动相机，点击适应窗口恢复自动适配。适配不改 VOI、当前切片或准星世界坐标，尺寸变化后重投影准星。序列缩略图在 52px 方框内预留 4px 黑边，保留完整宽高比与首尾像素边界。

当前 2×2 / 1+3 为 Stack + MPR 三视图，不是通用独立分屏。普通分屏属于后续能力，不能通过对单层数据开放 MPR 冒充。

### 顶栏品牌标识恢复（2026-10-30）

左上角打开文件夹前显示既有 ODV 方形标识与 OpenDicomViewer 项目名；静态品牌展示，不绑定跳转或清空检查。窄窗保留项目名，顶栏允许换行。

### 主题交互恢复（2026-10-30）

主题按钮恢复直接切换：深色下显示太阳与「浅色」，浅色下显示月亮与「深色」，文字表示点击后的目标主题。不使用下拉菜单；仍复用 store.setTheme 同步设置面板、DOM 与本地主题偏好。
